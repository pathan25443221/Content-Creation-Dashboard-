# ClipForge 🎬

ClipForge is a local, AI-powered pipeline that automatically turns long-form videos into high-retention vertical short-form content (YouTube Shorts, Instagram Reels, TikToks).

It downloads videos, transcribes them using local models (Whisper), uses a local LLM (Ollama + LLaMA 3) to heuristically select the highest retention hooks, and auto-generates vertical clips with burnt-in captions.

We have prepared a comprehensive, step-by-step guide to get this entire pipeline running on your own machine, connected to your own YouTube and Instagram accounts (for free).
